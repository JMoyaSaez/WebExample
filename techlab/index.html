DUDAS FRECUENTES

Preguntas frecuentes

Este proyecto es una demostración de desarrollo frontend. Los eventos y las reservas son ficticios.

¿La reserva es real?

No. Al pulsar «Confirmar reserva», JavaScript valida los datos y muestra una confirmación local. No hay backend ni se envía información a terceros.

¿Puedo probar la web en el móvil?

Sí. La interfaz se adapta automáticamente al ancho disponible. Puedes comprobarlo desde un teléfono o mediante el modo dispositivo de las herramientas del navegador.

¿Qué tecnologías utiliza?

HTML5 semántico, CSS3 con Grid y Flexbox, y JavaScript nativo para selección, validación y confirmación. No necesita instalar dependencias.
